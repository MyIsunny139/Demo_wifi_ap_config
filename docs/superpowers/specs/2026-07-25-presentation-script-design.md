# 15 分钟现场演讲稿设计

## 目标

为“基于 ESP32-S3 与 YOLO 的智能视频人员检测系统”编写一份可直接照读的中文演讲稿。听众为业务人员、管理人员和技术人员组成的混合群体，演讲总时长约 15 分钟，采用先演示、后解释的结构。

## 内容结构

1. 0:00-1:00：简短开场，说明系统用途和本次演示内容。
2. 1:00-7:00：现场演示双击启动、浏览器自动打开、实时视频、人员检测、风险等级、ESP32 状态灯联动和截图功能。
3. 7:00-10:30：解释 OV5640、ESP32-S3、WebSocket、Python、YOLO 和风险指令回传组成的数据链路。
4. 10:30-12:30：说明本地运行、无需云服务、绿色目录交付、日志记录和固定 IP 等工程特点。
5. 12:30-14:00：介绍适用场景和可扩展方向。
6. 14:00-15:00：总结并为现场操作延迟预留时间。

## 写作方式

- 正文使用自然、可直接朗读的口语，不采用宣传口号。
- 使用 `[现场操作]` 标出演讲者需要执行的动作。
- 使用 `[画面确认]` 标出继续讲解前应看到的结果。
- 为程序启动、视频连接、识别结果和状态灯异常准备简短备用话术。
- 技术解释以数据流为主，只保留混合听众能够理解且与演示直接相关的参数。

## 现场演示范围

演示从交付目录中的 `video-ai.exe` 开始。程序隐藏命令行窗口并自动打开浏览器，默认连接固定地址 `192.168.1.3`，接收 ESP32 JPEG 视频流，在本地 CPU 上执行人员检测，再把风险等级发送给 ESP32 控制 WS2812。演示结束前展示截图目录；日志只说明位置，不在现场展开阅读。

## 交付物

生成一份中文 Markdown 演讲稿，包含演讲前检查清单、逐分钟完整讲稿、演示操作标记、异常备用话术和演讲结束后的常见问答。正文控制在正常语速加现场操作约 15 分钟。
