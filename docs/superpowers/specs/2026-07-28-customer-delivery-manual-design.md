# video-ai 客户交付手册设计

## 目标与读者

为接收当前 `dist\video-ai` 绿色目录版的客户制作一份中文 Word 使用手册。读者不需要 Python、ESP-IDF 或源码知识，按照文档即可完成接线检查、启动、日常操作、关闭服务和常见故障排查。

## 交付格式

- 最终文件：`docs/video-ai-客户交付使用手册.docx`
- 仅交付 DOCX，不附带内部渲染图片。
- 文档约 7 至 9 页，重点是现场使用和演示，不包含源码编译、二次开发或重新打包说明。

## 内容结构

1. 封面与交付范围：说明必须完整保留 `video-ai.exe`、`_internal` 和随包文件。
2. 系统说明：说明 ESP32-S3、OV5640、Wi-Fi、WebSocket、YOLO、浏览器仪表盘、WS2812 和蜂鸣器之间的数据流。
3. 硬件接线：列出摄像头引脚、GPIO48 状态灯、GPIO14 MH-FMD 蜂鸣器以及5V供电、共地和电平安全要求。
4. 安装启动：说明 Windows x64、同一局域网、ESP32 固定 IP `192.168.1.3`、双击 EXE、浏览器地址和日志位置。
5. 操作流程：说明启动检测、停止检测、阈值设置、画面与风险状态、截图保存和三档声光行为。
6. 关闭服务：明确关闭浏览器不会结束后台服务；当前版本隐藏终端，通过任务管理器或 `taskkill /IM video-ai.exe /T /F` 关闭。
7. 常见故障：覆盖程序无法启动、网页打不开、ESP32 离线、视频异常、推理慢、端口占用以及状态灯或蜂鸣器无响应。

## 版式

采用 `compact_reference_guide` 预设和 `customer_pack` 首页模式。页面为 Letter 纵向，四边1英寸，正文11磅、1.25倍行距；一级标题16磅，二级标题13磅。中文字体使用微软雅黑，英文和数字使用 Calibri。标题与表头使用克制的蓝色，警告使用浅黄色或浅红色提示框。

表格只用于接线、风险状态和故障对照，全部使用固定 DXA 宽度和可自动扩展的行高。操作步骤使用真实编号列表，注意事项使用短提示框，页眉显示系统名称，页脚显示页码。

## 准确性约束

- 文档以当前工程和当前绿色目录版为准，不描述已取消的单文件重新打包方案。
- 客户无需安装 Python；必须复制完整交付目录，不能只复制 EXE。
- 默认 ESP32 地址为 `192.168.1.3`，视频端口为81，本地仪表盘地址为 `http://127.0.0.1:8000`。
- 日志位于交付目录的 `logs\video-ai.log`，截图位于 `captures\`。
- 蜂鸣器说明按当前 GPIO14、2kHz PWM 设计编写，并提示输入端不得向 ESP32 回灌5V。

## 验证

生成 DOCX 后使用文档技能提供的 `render_docx.py` 渲染全部页面。逐页检查中文字体、标题层级、表格宽度、换行、页码、分页和警告框；修正后重新渲染，直到没有重叠、裁切、孤立标题或大面积空白。最后检查 DOCX 中不存在临时占位符、编造信息或与当前工程不一致的操作。
